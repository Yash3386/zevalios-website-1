Cookies Policy

Last updated: 29 July 2026

1. Current use of cookies and browser storage

This website does not use analytics, advertising or behavioural-profiling cookies. It uses limited browser storage after a user action to remember the selected day/night theme and whether the storage notice has been dismissed. If enabled, Netlify Web Analytics measures traffic from server logs without placing analytics cookies or loading a client-side analytics script.

2. Essential storage

zevalios-themeLocal storageRemembers the day or night theme selected by the user.Until removed through the browser.
zevalios-storage-noticeLocal storageRemembers that the user dismissed the informational storage notice.Six months.

3. Server-side website analytics

Zevalios may enable Netlify Web Analytics to access a private dashboard containing aggregated pageviews, unique-visitor estimates, popular pages, referral sources, locations, bandwidth and missing-resource reports. Netlify derives these metrics from Content Delivery Network server logs. It does not identify visitors to Zevalios by name and does not set analytics cookies. A private analytics page is therefore not embedded in the public website; access remains within the authenticated Netlify account.

4. Google Fonts

The website loads typography from Google Fonts. This may cause the browser to request font files from Google and disclose technical connection information such as the Internet Protocol address. Google Fonts are not used by Zevalios for advertising or analytics on this site.

5. Managing stored information

The information panel can be reopened through the “Cookie information” link in the footer. Browser storage can also be cleared through the browser settings. Clearing it will reset the selected theme and cause the information notice to appear again.

6. Contact

Questions about this policy may be sent to privacy@zevalios.com.
