# Zevalios Netlify Website

Original static website for GitHub and Netlify. No Webflow, Wix, external framework, external font, analytics or advertising dependency is included.

## Structure
- Home, Services, Approach, About and Contact pages
- Four equal service-detail pages
- Privacy Notice, Technology Storage Notice, Terms of Use and Consultancy Disclaimer
- Netlify contact form: `zevalios-enquiry`
- Security headers and `www` redirect in `netlify.toml`

## Deploy
Upload the contents of this folder to the root of a GitHub repository and connect the repository to Netlify. Build command: blank. Publish directory: `.`

## Before production
1. Confirm the legal identity and geographic address required for the final trading entity.
2. Confirm `yash@zevalios.com` and notification routing.
3. Review the privacy notice against the final Netlify account, email provider and retention practice.
4. Do not add analytics or embedded media without updating the technology notice and consent mechanism where required.
5. External statistics on the homepage are cited and qualified; review periodically for continued accuracy.
