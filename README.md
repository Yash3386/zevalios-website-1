# Zevalios website

Original static HTML, CSS and JavaScript website prepared for Netlify.

## Deploy
Upload the contents of this folder to the root of a GitHub repository and connect it to Netlify. There is no build command; the publish directory is `.`.

## Included
- Homepage preserving the approved visual format
- Services overview and five individual service pages
- Netlify enquiry form and success page
- Privacy Policy, Cookies Policy, Website Terms & Conditions and Consultancy Disclaimer
- Informational essential-storage popup and detail panel
- Responsive day/night theme
- Redirects from earlier service URLs
- Sitemap, robots file, web manifest and security headers

## Final commercial refinements
- Presents five distinct, equally important services that can stand alone or be combined
- Keeps Diagnose, Redesign, Implement and Verify as the four core delivery stages
- Presents follow-up reviews as defined checkpoints within scope or commissioned separately
- Shortens the founder section while retaining the most credible evidence
- Distinguishes deal-specific documentation coordination from reusable templates and operating tools
- Uses broader, more defensible external evidence on late payment and information-search inefficiency
