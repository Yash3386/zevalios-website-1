# Zevalios website

Original static HTML/CSS/JavaScript website prepared for Netlify.

## Deploy
Upload the contents of this folder to the root of a GitHub repository and connect it to Netlify. There is no build command; the publish directory is `.`.

## Included
- Home page preserving the approved visual format
- Services overview and five service pages
- Netlify enquiry form
- Privacy, cookies, website terms and consultancy disclaimer
- Cookie preference popup
- Responsive day/night theme
- Redirects from earlier service URLs

## Important
Review legal pages and public contact details when the final legal entity and registered address are confirmed.
